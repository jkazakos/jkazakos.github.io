# Welcome to My Portfolio

**A modern, high-performance web application showcasing my projects and experience.**

👉 **[View My Live Portfolio Here](https://portfolio-iasonas-kazakos.vercel.app/)**

### Core Technologies

- **Frontend:** Built with [Astro](https://astro.build/) for lightning-fast page loads and optimized asset delivery.
- **Backend:** Powered by high-speed APIs written in **Go**.
- **Deployment & Hosting:** Deployed directly to the edge using [Vercel](https://vercel.com/).

_Note: This specific repository serves as the public routing gateway for the live domain. To protect the deployment state and backend configurations, the actual source code is maintained in a separate, private repository._
